## 1. ภาพรวม

แอปบนมือถือสำหรับพนักงานหน้าร้านก๋วยเตี๋ยว: รับออเดอร์ต่อโต๊ะ/กลับบ้าน → ส่งใบครัว (เครื่องพิมพ์ 58mm) → สั่งเพิ่มได้หลายรอบ → คิดเงิน (เงินสด / โอน QR พร้อมเพย์ / แยกจ่าย)

- Stack ที่ตั้งใจ: **Elixir / Phoenix LiveView** + Tailwind
- ผู้ใช้หลายคนใช้เครื่องเดียวกันได้ (login ด้วยชื่อ + PIN 4 หลัก)
- 15 โต๊ะ (ตั้งค่าได้)

| สั่งเพิ่ม · ย้ายโต๊ะ | ✓ | ✓ | ✓ |
| แก้/ลบรายการที่ยังไม่ส่ง | ✓ | ✓ | ✓ |
| **ยกเลิกรายการที่ส่งครัวแล้ว** (ไม่ต้องใส่รหัสยืนยัน) | ✓ | ✓ | ✓ |

| ปิด/เปิดขาย (หมดวันนี้) | – | ✓ | ✓ |

| บัญชี · ตั้งค่าร้าน | – | – | ✓ |

- เมนูที่ไม่มีสิทธิ์: **เห็นแต่เป็นสีเทา** (ไม่มีไอคอนกุญแจ) แตะแล้วขึ้น toast
- เจ้าของมีคนเดียว (ไม่มีให้เลือกตอนเพิ่มพนักงาน)

```
                ├─ย้ายโต๊ะ──► 0b2 (เลือกได้เฉพาะโต๊ะว่าง · พิมพ์ใบแจ้งครัว "โต๊ะ 1 → 7")
                ├─ซื้อกลับบ้าน──► 0a (บิล ก3 · ชื่อลูกค้า) → 0b … → 0a-2 สรุปบิลกลับบ้าน

                └─แถบล่าง: จัดการเมนู (1a) · ยอดขาย · บัญชี · ตั้งค่า (0-set → 00c/00d/00e/00b)
```

## 4. กฎธุรกิจ (ตกลงแล้ว)

### ออเดอร์ / คิว
- สั่งให้ครบก่อน แล้วส่งครัวทีเดียวจากหน้าสรุป (ได้ใบครัว 1 ใบต่อรอบ)
- **ทุกครั้งที่ส่งครัว = เลขคิวใหม่ต่อท้ายคิวรวมของร้าน** (รอบ 2 ของโต๊ะ 1 อาจเป็น #7)
- โต๊ะแสดงคิวทุกรอบ เช่น `#3 #7`
- **สถานะดูได้อย่างเดียว** ไม่มี "กำลังทำ/เสร็จ" — ครัวและหน้าร้านไม่กดเปลี่ยนสถานะ
- โต๊ะกลับเป็นว่าง **เมื่อคิดเงินแล้วเท่านั้น**
- ใบครัวรอบ 2 พิมพ์เฉพาะของใหม่ + บอก "สั่งเพิ่ม · โต๊ะเดิม (รอบแรก #3)"
- ใส่ถุงกลับบ้าน: เลือกได้ต่อชาม/ต่อรายการ (switch ท้ายหน้าตัวเลือก หรือสลับในหน้าสรุป) — **ไม่มีค่าถุง**
- ใบครัว/ใบเสร็จ: ดูรายละเอียดทั้งหมดใน `PRINT.md`
- เมนูที่ตั้ง "พิมพ์ลงใบครัว = ปิด" (เช่น ขนมถุง, ไอศกรีม) ไม่ขึ้นใบครัว แต่ขึ้นบิล/ใบเสร็จ

### กลับบ้าน
- บิลเลข `ก1, ก2, …` + ชื่อลูกค้า (ไว้เรียก)
- ทุกรายการใส่ถุงอัตโนมัติ
- ส่วนใหญ่จ่ายก่อน: ปุ่มหลัก "ส่งครัว + คิดเงิน"

### เมนูหมด
- ผู้จัดการขึ้นไปปิด "หมดวันนี้" ได้ในหน้า 1a → เมนูขึ้นสีเทา กดสั่งไม่ได้ → **เปิดใหม่อัตโนมัติพรุ่งนี้**

## 5. ข้อมูลเมนู (จาก mockup — ยืนยันกับร้านก่อน seed)

**ก๋วยเตี๋ยว** (น้ำใส · น้ำตก · น้ำตกต้มยำ · ต้มยำ · แห้ง · แห้งต้มยำ · แห้งคลุก · เย็นตาโฟ · เย็นตาโฟต้มยำ · เกาเหลา)
- ขนาด: หมู/ไก่ ธรรมดา 50 / พิเศษ 60 · ถ้าเลือก **ทะเล** ราคาเป็น 90 / 130 และกาง panel "ทะเลใส่อะไร"
- เส้น (ต้องเลือก 1): เส้นเล็ก · เส้นใหญ่ · เส้นหมี่ขาว · บะหมี่ · มาม่า · วุ้นเส้น
- เนื้อสัตว์: หมูตุ๋น · หมูสับ · หมูหมัก · หมูแดง · ไก่ฉีก · ทะเล — ไม่เลือกก็ได้ถ้าเลือก "ลูกชิ้นล้วน"/"ผักล้วน"
- ตัวเลือกอื่น: ผักล้วน · ลูกชิ้นล้วน · เพิ่มเส้น+น้ำ +20
- ไข่ (stepper): +10 ต่อฟอง
- ไม่ใส่ (หลายอย่าง): ผัก · ผักโรย · ถั่ว · ถั่วงอก
- ลำดับในหน้า: ชามที่ N → เส้น → เนื้อสัตว์ → ตัวเลือกอื่น → ขนาด → ไข่ → ไม่ใส่ → หมายเหตุ → switch ใส่ถุง → ปุ่ม

**ข้าว** (0f–0f8): ข้าวมันไก่ (ไก่ต้ม/ทอด/ผสม · หนัง · น้ำจิ้ม) · ข้าวหน้าไก่ · ข้าวหมูแดง · ข้าวขาหมู · ข้าวหมูตุ๋น · ข้าวยำไก่แซ่บ · ข้าวคลุกกะปิ — ราคา/ตัวเลือกดูในแต่ละหน้า
**กับข้าว** (0g): เช่น ขาหมู เล็ก 60 / ใหญ่ 120 (หนัง/น้ำราด)
**เพิ่มเติม** (0h2): ข้าวสวย · ข้าวมัน · กากเจียว · เกี๊ยวทอด · ลูกชิ้นลวก 30/40/50
**เครื่องดื่ม**
- น้ำชง 12 รายการ (กาแฟ ชาไทย ชาเขียวนม นมชมพู ชามะนาว ชาเขียวมะนาว มะตูม กระเจี๊ยบ โอเลี้ยง อัญชันมะนาว ชาดำเย็น เก็กฮวย): **ขวด 20 / แก้ว 25 ไม่มีตัวเลือก** (ชงสูตรเดียว)
- น้ำเปล่า ขวด 10
- น้ำอัดลม: โค้ก ขวดแก้ว 15 / กระป๋อง 16 / แก้วใหญ่ 25 · โค้กซีโร่ เป๊ปซี่ แฟนต้าแดง แฟนต้าเขียว สไปรท์: กระป๋อง 16 / แก้วใหญ่ 25
**ไอศกรีม**: ลูกละ 10 · ถ้วย/โคน · หลายถ้วยต่อโต๊ะ แต่ละถ้วยหลายลูกหลายรส (หน้าเดียว 0e)
**ขนมถุง**: 30 / 35 · ไม่มีตัวเลือก แตะ = 1 ถุง

## 8. ยังไม่มีหน้า (ต้องออกแบบเพิ่มหรือให้ Claude Code เสนอ)

- **สำคัญ:** รายการบิลกลับบ้านที่ค้าง (บนหน้าแรก) · ยกเลิกรายการที่ส่งครัวแล้ว + ใบแจ้งยกเลิกเข้าครัว · หน้าจ่ายสำเร็จ / ใบเสร็จโต๊ะในร้าน
- ยอดขาย · บัญชี · สรุปยอดสิ้นวัน
- หน้าย่อยในตั้งค่า: โต๊ะ · เครื่องพิมพ์ · เลขคิว · ใบเสร็จ · แก้ไขพนักงาน (ใช้ 00d โหมดแก้)
- สถานะ: ผลค้นหาเมนู · PIN ผิด · เครื่องพิมพ์หลุดตอนส่งครัว · เน็ตหลุด/กดส่งซ้ำ · รสไอศกรีมหมด
- ปุ่มแยกจ่ายในหน้าโอน 0j-2 · เพิ่มหมวดใหม่ · ลบ/เรียงเมนู

## 9. เคสทดสอบที่ต้องผ่าน

- ไม่เลือกเนื้อ เลือกลูกชิ้นล้วน (0c4) · ทะเล + ไข่ 3 ฟอง ราคาถูก
- โต๊ะเดียวห่อกลับบางชาม → ใบครัวแยกกลุ่มใส่ถุง
- สั่งเพิ่มรอบ 2 ขณะรอบแรกยังไม่เสร็จ → คิวใหม่ต่อท้าย ใบครัวพิมพ์เฉพาะของใหม่
- ลดจำนวนในสรุปจนเหลือ 0 = ลบรายการ
- กดส่งครัวซ้ำ / เน็ตหลุดตอนกดส่ง → ต้องไม่พิมพ์ใบซ้ำ ไม่สร้างคิวซ้ำ (idempotent)
- ย้ายโต๊ะที่มีของส่งครัวแล้ว → พิมพ์ใบแจ้งครัว
- พนักงานแตะ "ยอดขาย" → toast ไม่มีสิทธิ์ · ตั้ง PIN ใหม่ → เครื่องที่ค้างชื่อนั้นเด้งออก
