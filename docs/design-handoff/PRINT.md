# PRINT — ใบครัว / ใบเสร็จ (thermal printer)

> แยกจาก `DESIGN_SYSTEM.md` เพราะไม่ได้ render บนจอ แต่ส่งไปเครื่องพิมพ์ความร้อน
> ตัวอย่างหน้าตา: `print/samples.html` (ความกว้างตามกระดาษจริง) · mockup บน canvas: 0i-5, 0i-7, 0g3, 0a-3, 0a-4

## 1. เครื่องพิมพ์ (ยืนยันรุ่นจริงกับร้านก่อนทำ)

| | ค่าที่ออกแบบไว้ |
|---|---|
| กระดาษ | 58 mm |
| พื้นที่พิมพ์ | ~48 mm = **384 dots** ที่ 203 dpi |
| ตัวอักษร (text mode) | Font A 12×24 = **32 ตัว/บรรทัด** |
| การเชื่อมต่อ | Bluetooth (ตั้งค่าที่ ตั้งค่า → เครื่องพิมพ์ใบครัว) |
| คำสั่ง | ESC/POS |
| ตัดกระดาษ | 58mm ส่วนใหญ่ไม่มี cutter → feed 3–4 บรรทัดท้ายใบให้ฉีกได้ |

## 2. ภาษาไทย — แนะนำพิมพ์เป็นรูป (raster)

สระบน/ล่างและวรรณยุกต์ไทยต้องซ้อนกันในตำแหน่งเดียว เครื่องพิมพ์ราคาถูกหลายรุ่นพิมพ์ใน text mode (code page TIS-620 / CP874) แล้วสระลอยหรือเหลื่อม และขยายตัวอักษรใหญ่ไม่สวย

**วิธีที่แนะนำ:** สร้างใบเป็นภาพขาวดำกว้าง 384px (ฟอนต์ IBM Plex Sans Thai) แล้วส่งด้วย `GS v 0` (raster bit image)
- ได้หน้าตาเหมือน mockup ทุกอย่าง (เลขคิวตัวใหญ่ กรอบ แถบดำ)
- ข้อเสีย: ข้อมูลใหญ่กว่า text mode ส่ง Bluetooth ช้ากว่าเล็กน้อย (~1–2 วิ/ใบ)
- ทางสำรอง: text mode + code page ไทย ถ้าทดสอบกับเครื่องจริงแล้วสระไม่เพี้ยน

ให้ Claude Code เลือกว่าจะ render ภาพฝั่งไหน (server เช่น Elixir + image lib / หรือฝั่ง client) ตามวิธีที่แอปคุยกับเครื่องพิมพ์ — **Web Bluetooth ใช้ไม่ได้บน iPhone (Safari)** ถ้าพนักงานใช้ iPhone ต้องมีตัวกลาง (แอป native, print server ในร้าน หรือเครื่องพิมพ์ LAN/Wi-Fi)

## 3. กฎการพิมพ์

- กดส่งครัว 1 ครั้ง = ใบครัว 1 ใบ = เลขคิวใหม่ 1 เลข (ต่อท้ายคิวรวมของร้าน)
- **กดซ้ำ / เน็ตหลุด / พิมพ์ไม่สำเร็จ ต้องไม่สร้างคิวซ้ำ** — ใช้ idempotency key ต่อรอบ และมีปุ่ม "พิมพ์ซ้ำ" ที่พิมพ์ใบเดิม (มีคำว่า "พิมพ์ซ้ำ" บนหัว)
- เมนูที่ตั้ง `print_to_kitchen = false` (ขนมถุง ไอศกรีม ฯลฯ) ไม่ขึ้นใบครัว แต่ขึ้นใบเสร็จ
- ใบครัวรอบ 2+ พิมพ์เฉพาะของใหม่
- ย้ายโต๊ะที่ส่งครัวแล้ว → ใบแจ้ง "โต๊ะ 1 → 7" (ถ้าเปิด switch ตอนย้าย)
- ยกเลิกรายการที่ส่งครัวแล้ว → ใบแจ้งยกเลิก (ยังไม่มี mockup — ดูข้อ 6)

## 4. ใบครัว (Kitchen ticket)

ลำดับจากบนลงล่าง:

1. **หัว:** ซ้าย = เลขคิว ใหญ่ที่สุดในใบ (`#3`) · ขวา = `โต๊ะ 1` + `รอบ 1` หรือ `กลับบ้าน` + `บิล ก3 · ชื่อลูกค้า`
2. รอบ 2+: บรรทัด `สั่งเพิ่ม · โต๊ะเดิม (รอบแรก #3)`
3. **meta:** `10:53 · 4 รายการ · ใส่ถุง 2` (+ `จ่ายแล้ว` ถ้ากลับบ้านจ่ายก่อน) แล้วเส้นประ
4. **กลุ่ม "กินที่ร้าน"** (ถ้ามีทั้งสองแบบ)
5. **รายการ:** ชื่อเมนู + ขนาด (ตัวหนา) · จำนวน `×N` ชิดขวา (ตัวหนาใหญ่) · บรรทัดถัดไป = ตัวเลือก คั่นด้วย ` · `
6. **หมายเหตุ:** กรอบดำ 2px `★ หมายเหตุ: …` ตัวหนา
7. **กลุ่มใส่ถุง:** แถบดำตัวขาว `🛍 ใส่ถุงกลับบ้าน (N)` แล้วกรอบดำรอบรายการกลุ่มนั้น (บิลกลับบ้านทั้งใบ = `ใส่ถุงทั้งหมด`)
8. **ท้าย:** เส้นประ · `ทั้งหมด N รายการ · พิมพ์ HH:MM` · ถ้ามีเมนูที่ไม่พิมพ์ บอก `ขนมถุงไม่พิมพ์ (หยิบหน้าร้าน)`

ขนาดใน raster 384px (โดยประมาณ): เลขคิว 64px · หัวขวา 30px · รายการ 24px ตัวหนา · จำนวน 26px · ตัวเลือก 19px · meta 16px

## 5. ใบเสร็จลูกค้า (Receipt)

1. ชื่อร้าน `เสน่ห์ร้อยรส` กลาง ตัวหนา · บรรทัดรอง `ก๋วยเตี๋ยวเรือ · โนนสูง` (แก้ได้ที่ ตั้งค่า → ใบเสร็จ)
2. กรอบ: `กลับบ้าน · พี่แดง` / `โต๊ะ 1` + เลขคิว
3. `บิล ก3 · 16/11/69 11:20` · `รับโดย นิด` แล้วเส้นประ
4. รายการ: `N×  ชื่อ ขนาด  ราคา` (ราคาชิดขวา) + บรรทัดตัวเลือกเยื้องเข้า — **รวมทุกเมนู** รวมที่ไม่ขึ้นใบครัว
5. สรุป: `รวม N ชิ้น` · `ค่าถุง 0` · **`ยอดชำระ 220 บาท`** (ใหญ่สุด) · `เงินสด 500` · `ทอน 280` / หรือ `โอน (พร้อมเพย์)`
6. แยกจ่าย: พิมพ์ใบต่อคน `คนที่ 2/3` และยอดของคนนั้น
7. ท้าย: `ขอบคุณค่ะ` + ข้อความท้ายใบที่ตั้งได้ (กลับบ้าน: `ยื่นใบนี้ตอนรับของ · เรียกตามเลขคิว`)
8. วันที่ใช้ปี พ.ศ. แบบย่อ (69)

## 6. ยังไม่มี mockup

- ใบแจ้งยกเลิกรายการ (`✕ ยกเลิก` + คิวเดิม + รายการที่ยกเลิก)
- ใบแจ้งย้ายโต๊ะ
- ใบพิมพ์ซ้ำ
- ใบเสร็จโต๊ะในร้าน / ใบแยกจ่าย
- หน้าจอแจ้งเมื่อเครื่องพิมพ์ไม่เชื่อมต่อตอนกดส่งครัว (ควรบันทึกออเดอร์ไว้ก่อน แล้วให้พิมพ์ซ้ำได้)
